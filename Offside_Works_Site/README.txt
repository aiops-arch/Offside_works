Offside Works Site

How to run:

1. Double-click RUN_OFFSIDE_SITE.bat
2. Your browser should open automatically.
3. Keep the black terminal window open while using the site.
4. Press Ctrl + C in that terminal to stop the server.

Manual run:

cd "C:\Users\spc1\Downloads\offside wors\Offside_Works_Site"
python -m http.server 8000

Then open:

http://localhost:8000/

Files:

index.html - the complete Offside Works website
RUN_OFFSIDE_SITE.bat - Windows launcher
